# MyRupeeBot 🟢 — בוט מלאי לטלגרם

הבוט בודק מוצרים באמזון ובחנויות אחרות, ושולח הודעה לקבוצת הטלגרם כשמוצר חוזר למלאי וכשהוא אוזל.

## איך זה עובד

- **💻 המחשב (עיקרי):** `start_bot.bat` מריץ את הבוט. כל מוצר נבדק בערך כל 90 שניות, ובשעות חמות מהר יותר. הבוט עונה לכפתורים מיד.
- **☁️ הענן (גיבוי):** GitHub Actions רץ כל 15 דקות. כל עוד המחשב מדווח שהוא פעיל, הריצה בענן לא עושה כלום. אם המחשב שותק יותר מ־25 דקות (שינה או כיבוי), הענן ממשיך לבדוק במקומו, וכשהמחשב חוזר הוא ממשיך מאותה נקודה.
- **המצב המשותף** נשמר בענף `live` (בקובץ `live.json`): המוצרים, הסטטוסים, ההיסטוריה ו"דופק" מהמחשב.

## קבצים במחשב (`C:\MyRupeeBot`)

| קובץ | מה זה |
|---|---|
| `bot.py` | הבוט |
| `start_bot.bat` | הפעלה (מתקין לבד את מה שצריך) |
| `autostart_on.bat` / `autostart_off.bat` | הפעלה אוטומטית עם Windows |
| `config.json` | טוקן טלגרם, טוקן GitHub לגיבוי, וקצב הבדיקה (`CHECK_SECONDS`) |
| `products.json`, `state.json` | הרשימה והמצב (נשמרים גם בענן) |

## פקודות בקבוצה

| פקודה / כפתור | מה עושה |
|---|---|
| `/add קישור [שם]` | הוספת מוצר (מנהלי הקבוצה בלבד) |
| `/remove מספר` | הסרת מוצר (מנהלי הקבוצה בלבד) |
| 📋 כל המוצרים · `/list` | כל המוצרים והסטטוס |
| 🛒 מה זמין עכשיו? | רק מה שבמלאי |
| 🔄 בדוק עכשיו · `/check` | בדיקה מיידית |
| ℹ️ סטטוס · `/status` | מאיפה הבוט רץ, בדיקה אחרונה, קצב, captcha |
| 📊 סטטיסטיקה · `/stats` | חזרות למלאי, כמה זמן החזיק, שעות חמות |
| 🆕 מה חדש · `/update` | שינויים בגרסה האחרונה (`/update all` לכולן) |

## טוב לדעת

- **מוכר מסוים:** קישור אמזון עם `smid=` יתריע רק כשהמוכר הזה מוכר.
- **"אזל"** מוכרז רק אחרי 2 בדיקות ברצף. הודעת ה־🚨 נערכת לשורת "המלאי אזל" עם משך הזמן שהמוצר היה במלאי.
- **חסימות של אמזון:** הבוט מאט לבד (captcha פי 1.2, חסימה פי 1.5) וחוזר בהדרגה למהירות.
- **טוקן GitHub פג?** הבוט יכתוב בקבוצה שהגיבוי לא מצליח לשמור. צריך ליצור טוקן חדש ולהחליף אותו ב־`config.json`.
- **שינוי גרסה:** מעלים את `VERSION` ומוסיפים שורות בראש `CHANGELOG` ב־`bot.py`. בהפעלה הראשונה הבוט שולח לקבוצה את "מה חדש".
