# בוט מלאי לטלגרם 🟢

הבוט בודק כל 15 דקות את המוצרים ברשימה, ושולח הודעה לקבוצת הטלגרם ברגע שמוצר חוזר למלאי.
עובד עם אמזון (כל המדינות), חנויות Shopify, ורוב החנויות האחרות.
חינם לגמרי ורץ על GitHub, גם כשהמחשב כבוי.

---

## איך זה מחובר

- **הבוט בטלגרם:** @MyRupeeBot (הטוקן שמור כ־Secret בשם `TELEGRAM_TOKEN`, לא בקבצים).
- **הקבוצה:** הקבוצה הראשונה ששולחת לבוט פקודה (למשל `/help`) הופכת לקבוצה שלו. הבוט עונה ומתריע רק בה.
- **ההרצה:** GitHub Actions מריץ את `bot.py` כל 15 דקות. אפשר להריץ ידנית: **Actions ← Stock check ← Run workflow**.
- **החלפת קבוצה:** מוחקים את השורה `chat_id` מהקובץ `state.json` ושולחים `/help` בקבוצה החדשה.

---

## שימוש יומיומי (הכל מתוך הקבוצה בטלגרם)

**תפריט:** שלחו `/menu` והכפתורים יופיעו מתחת לתיבת ההודעה:
🛒 מה זמין עכשיו? · 📋 כל המוצרים · 🔄 בדוק עכשיו · 📖 הוראות שימוש

| פקודה | מה עושה |
|---|---|
| `/add קישור` | מוסיף מוצר (אפשר גם `/add קישור שם`) |
| `/list` | כל המוצרים והסטטוס |
| `/remove 2` | מסיר את מוצר מספר 2 |
| `/menu` | מציג את התפריט והוראות |

**הודעות:** כשמוצר חוזר למלאי נשלחת הודעת 🚨 עם ID, מחיר, שעה וכפתור "מעבר לרכישה". כשהוא אוזל נשלחת שורה קצרה.

**מוכר מסוים:** קישור אמזון עם `smid=` (קוד מוכר) יתריע רק כשהמוכר הזה מוכר את המוצר.

⏱ ב־GitHub הבוט עונה בסבב הבדיקה הבא (עד 15 דקות). על המחשב הוא עונה מיד.

---

## הרצה על המחשב (אם אמזון חוסמת את GitHub)

1. מתקינים Python מ־python.org (מסמנים **Add python.exe to PATH**).
2. מורידים את הריפו: **Code ← Download ZIP** ומחלצים לתיקייה.
3. יוצרים בתיקייה קובץ `config.json`:
   ```json
   { "TELEGRAM_TOKEN": "הטוקן של הבוט", "CHECK_MINUTES": 5 }
   ```
4. **חשוב:** ב־GitHub עוצרים את ההרצה האוטומטית: **Actions ← Stock check ← ⋯ ← Disable workflow** (אחרת שני הבוטים יתנגשו).
5. לחיצה כפולה על `start_bot.bat`. החלון צריך להישאר פתוח.

---

## טוב לדעת

- **ההתראה נשלחת רק במעבר מ"אזל" ל"במלאי"**, כך שאין הודעות כפולות.
- **אמזון חוסמת לפעמים.** במקרה כזה הבוט פשוט מדלג ומנסה בסבב הבא. אם זה נמשך כ־3 שעות ברצף, תגיע הודעת אזהרה.
- **חנות שהבוט לא מזהה נכון:** אפשר לערוך את `products.json` ב־GitHub ולהוסיף למוצר מילה שמופיעה בעמוד כשאין מלאי, למשל:
  ```json
  { "url": "https://...", "name": "שם", "out_text": "אזל מהמלאי" }
  ```
- **לשנות תדירות:** ב־`check.yml` משנים את `*/15` ל־`*/10` (כל 10 דקות) או `*/30`.
